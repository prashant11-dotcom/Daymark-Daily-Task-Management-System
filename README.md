## Overview
Daymark is a browser-based task manager for listing everyday work, setting due dates and priorities, updating status and reviewing progress. It uses HTML, CSS and JavaScript. Task data is saved in browser LocalStorage; there is no server or shared database.

## Features
- Add tasks with name, optional description, due date, priority and status.
- Edit and delete tasks (deletion asks for confirmation).
- Mark tasks completed or pending.
- Search task names and descriptions; filter by priority.
- View all, today, upcoming and completed tasks.
- Dashboard counts, overdue indicator and completion progress bar.
- Responsive layout for desktop and mobile.

## Run
1. Download or clone this repository.
2. Open `04_Website/index.html` in a modern browser.
3. Add or edit tasks. The browser saves the list automatically.
No package installation or backend server is needed. Internet is only optional for Google Fonts.

## Storage limitation
Tasks stay in the current browser profile. They do not sync to another device or browser. Clearing browser data can remove them. Do not store confidential information.

## Suggested demo
Add a task, edit it, search for it, filter by priority, mark it complete, refresh the page to demonstrate LocalStorage, then delete it.
